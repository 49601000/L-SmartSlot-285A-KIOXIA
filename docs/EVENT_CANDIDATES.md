## 運用上の前提

1. **ニュースの事実／報道による解釈／ゲーム上の演出案を分離**する。株価の変化が特定ニュースだけで起きたと断定しない。
2. 日付には「発表日・報告書提出日・売買実施日・効力発生日・相場期間」の違いがある。日付が曖昧な項目は年月または期間で保持し、勝手に単一営業日に確定しない。
3. この台帳は**イベント候補の保存用**。採用判定・発生確率・CZ/ATへの効果・ニュース再生タイミングは未決定。
4. 株価参照データは data/285A_daily_close.json（終値のみ）。決算発表が大引け後なら、同日の終値は「決算を受けた反応」ではない。
5. 分割前の株価と分割後株価、ニュース記事の引用数値は**同一株式数基準に揃えてから**比較する。株価下落率も未算定のまま扱う。
6. 出典リンクには提供資料からの転記を含む。**リンクの存在は、主張が裏取り済みであることを意味しない。**
