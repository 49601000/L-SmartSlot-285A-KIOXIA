# 演出仕様 — 2系統の演出エンジン

Status: 仕様固定（2026-11-14、オーナー決定）。エンジン自体は未実装で、現行の表示は暫定実装（後述）。
素材の一覧と状態は `data/materials.json`（素材レジストリ）を正とする。

## 原則: 素材と演出の意味を分離する

素材は「何が・いつ・どこで起きたか」の記録であり、演出は「それをどう見せるか」である。
素材ごとに **イベントID（EVT-*）・発生日・出典・演出タイプ** を持たせれば、素材が増えても
ゲーム本体の構造は変えず、内部の抽選・進行処理は共通化できる。

## エンジンA: 全文テキストスクロール型（text_scroll）

- 対象: ニュース記事、SNS投稿、掲示板レス。
- 表示: 原文テキストを液晶内で **下から上へ連続スクロール** させる。記事・投稿・掲示板レスは同じ表示エンジンを使う。
- 原文は改変しない（後知恵で書き換えない）。改行・>>参照は保持する。
- 例:
  - ベインEXIT報道（MAT-NEWS-20260709-BAIN、EVT-010）
  - AI相場への説教ポスト（MAT-SNS-20260621-TOP、EVT-008）
  - Yahoo!ファイナンス掲示板の投稿群（MAT-BOARD-285A）

## エンジンB: 原本画像表示型（original_image）

- 対象: 公式IR・決算資料（適時開示PDF、決算短信など）。
- 表示: PDFのページを画像化し、**原本の紙面そのまま** を液晶に表示する。ゆっくり拡大・移動（パン／ズーム）させたり、複数ページを切り替えたりする。
- IRの本文をテキスト化してスクロールさせることはしない。無機質な決算資料の紙面が突然液晶全面に現れること自体が演出である。
- 例: 決算短信、株式分割のお知らせ、主要株主である筆頭株主の異動に関するお知らせ、設備投資（サンディスクとの投資計画）発表。
- 素材化パイプライン（2026-11-14にパイロットで確立）:
  1. 公式IRニュース一覧の各リンクからPDFの実URL（ssl4.eir-parts.net のTDnet文書）を特定する。
  2. PDFをダウンロードする（PDF自体はリポジトリに保管しない。出典として `pdf_url` をレジストリに記録する）。
  3. `scripts/convert_ir_pdf.py <pdf> <素材ID>` でページ画像化する: **JPEG・150dpi・品質85、原本無加工**（切り抜き・テキスト化・再組版をしない）→ `materials/ir/<素材ID>/page-XX.jpg`。
  4. レジストリの `images` / `pages` / `pdf_url` を更新し、`status` を `stored_image` にする。
- パイロット実績（2026-11-14）: 7件・44ページを取得済み（上場のお知らせ／株式分割／2027年3月期Q1決算短信18頁／筆頭株主異動／サンディスク投資計画／初配当・株主還元方針／同Q2決算短信18頁）。残り71件はメタデータのみ。

## 同じイベントでも系統は素材で決まる

2026-07-31の決算短信はIR（エンジンB）。2026-06-21のAI相場説教ポストはSNS（エンジンA）。
イベントIDが同じでも、素材の出所と性質によって系統が決まる。系統はイベントではなく素材の属性である。

## 素材レジストリ（data/materials.json）

各素材は次の項目を持つ:

| 項目 | 内容 |
|---|---|
| `id` | 素材ID。`MAT-<種別>-<日付>-<短縮名>`（掲示板コレクション等は日付なしも可） |
| `kind` | `news` / `sns` / `board` / `ir` |
| `presentation` | `text_scroll`（エンジンA）または `original_image`（エンジンB） |
| `event_id` | 関連するイベント候補ID（EVT-*）。無ければ null |
| `date` | 発生日（報道日・投稿日・発表日。種類は素材ごとに注記） |
| `title` | 素材の題名（IRは公式タイトル） |
| `source` | 出典 |
| `content_path` | リポジトリ内の素材本体の場所（テキスト素材・掲示板） |
| `images` | エンジンB用のページ画像のパス一覧（未取得なら空） |
| `status` | `stored_text` / `stored_normalized` / `metadata_only`（メタデータのみ・画像未取得）など |
| `suggestion` | 演出示唆（任意。採用済み仕様と混同しない） |

## 現行実装との対応（2026-11-14時点）

| 仕様 | 現行 |
|---|---|

| エンジンB（IR原本画像） | **未実装**。ただし素材側は前進: IR 78件のメタデータを登録し、うちパイロット7件・44ページはページ画像を取得済み（`materials/ir/`） |

## 未確定事項（オーナー判断待ち）

1. **発火条件**: 素材は対象の営業日に到達したら自動で流すのか、小役・CZ／ATの抽選と連動させるのか、専用の示唆から段階的に出すのか。
2. **スクロールの速度・長さ**: 全文を流し切るのか、ゲーム進行を止めるのか、レバー操作で中断できるのか。
3. **IR画像の表示時間とページ切替間隔**: 1ページあたりの表示秒数、ズーム／パンの範囲。
4. **掲示板のスクロール単位**: レスを連続テキストとして流すのか、象徴的なレスを選んで流すのか（現行バー表示は全件ローテーション）。
5. **優先順位**: 同じ日にエンジンAとBの素材が両方ある日の出し方（例: 2026-07-09はベイン報道＝Aと掲示板＝A、IRはなし。2026-10-30は決算短信＝Bと掲示板なし）。
