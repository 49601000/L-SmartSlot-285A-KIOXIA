# Specification — スマスロ285A キオクシア

Status: Initial demo implemented; historical close JSON imported (2026-11-01) and linked to the game screen (2026-11-14); board posts linked by trading day (2026-11-14).

## Purpose

キオクシア（285A）を題材にした非公式パロディの個人用ブラウザスロットデモ。実際の投資・株式取引機能はない。

## Runtime and components

- 静的HTML/CSS/JavaScript。エントリポイントは `index.html`。
- `script.js` はゲーム用の乱数抽選を使用。株価表示は下記の終値JSON連携（読み込めない環境では組み込みサンプル配列にフォールバック）。
- 設定1固定のデモ。CREDIT、PAYOUT、AT枚数、TOTAL Gを表示。
- CZ（NAND品薄CHANCE）、AT（SUPER CYCLE RUSH）、SUPER_AT、強制CZ/AT等のデバッグ操作あり。

## Price display linked to the close JSON (2026-11-14)

- 起動時に `data/285A_daily_close.json` を fetch し、成功したら実データ表示に切り替える。開始位置は上場日（2024-12-18、先頭レコード）。
- **1ゲーム = 1営業日**。レバーごとに次の営業日へ進み、最終営業日の次は上場日へ巻き戻す（デモ仕様。ステージ制を導入する場合は再検討する）。
- 表示項目: 取引日、終値、前日終値、前日比（円・%）、開始日からその日までの最高／最安終値、営業日の進捗（n / 全件数）、下部チッカーの285A価格。
- JSONは終値しか持たないため、始値・高値・安値・出来高は表示しない（ダッシュボードの詳細行は上記の終値由来の項目に置き換えた）。日経平均・SNDKのチッカーは従来どおりダミー表示のまま。
- fetchが失敗する環境（`file://` 直開き等）では、従来の組み込みサンプル株価配列（2025/02/10〜02/14の4件）で表示し、ゲーム自体は動作する。連携を確認するにはHTTP経由（GitHub Pages、またはローカルサーバー）で開くこと。
- リセットボタンは実データ連携時には上場日表示へ戻す。

## Presentation engines and material registry (2026-11-14, owner-approved design)

演出は2系統に固定する。詳細は `docs/PRESENTATION_SPEC.md`。

- **エンジンA（text_scroll）**: ニュース・SNS・掲示板。原文テキストを液晶内で下から上へ全文スクロール表示する。
- **エンジンB（original_image）**: 公式IR・決算資料。PDFページを画像化し、原本の紙面そのままを液晶に表示する（ゆっくり拡大・移動、ページ切替）。IR本文はテキストスクロールしない。
- 素材と演出の意味は分離する。各素材はイベントID・発生日・出典・演出タイプを持ち、素材台帳は `data/materials.json`（現在81件: テキスト素材2＋掲示板コレクション1＋IR 78件）。
- IR 78件は公式IRニュース一覧から転記したメタデータ（日付・カテゴリ・公式タイトル）で、ページ画像は未取得（status=metadata_only）。対象期間は価格データと同じ2024-12-18〜2026-10-30、50日に分布し、うち15件がEVT台帳と対応する。
- 両エンジンとも未実装。現在の掲示板バー表示はエンジンAの暫定表示、ランダムIR表示は仮演出。

## Board posts linked by trading day (2026-11-14)

- 素材: Yahoo!ファイナンス 285A掲示板の手作業取得テキストを整形したJSON 6ファイル（Drive「スマスロキオクシア」フォルダ保管）、合計19,727件。
- 正規化: `scripts/normalize_board_data.py` が3種の旧スキーマ（{number,date,time,text}／{id,datetime,text}／{number,datetime,message}）を統一形式 {number, date, time, text, thread} に変換し、`data/board/<営業日>.json` と `data/board/index.json` を生成する。番号はファイル横断で一意ではないため、同一性は (thread, number) で判定する。本文は改変しない。重複排除は (thread, number) の完全一致のみ（同文の別投稿は別投稿として保持）。
- 営業日への割り当て: 投稿日が営業日ならその日。土日・休日の投稿は次の営業日へ繰り越し、上場前（2024-11-25〜12-11）の投稿は上場日（2024-12-18）に表示する。各投稿は実日付を保持し、表示日と異なる場合は日付を前置表示する。
- 対応する営業日は8日: 2024-12-18（727件）／2026-06-11（2,532）／06-12（404）／06-22（5,899）／06-23（3,446、2スレッド合算）／06-29（4,319、週末分繰り越し）／07-09（1,780）／07-10（620）。カバー範囲は取得した時間帯のみで、全日・全時間帯を網羅しない（例: 2026-06-23は00:00–04:02と14:42–17:01の2区間）。
- 表示: 液晶下部の掲示板バーに、その営業日の投稿を時系列順に4秒間隔でローテーション表示（開始位置はランダム）。1件は「[日付] 時刻 No.番号 本文」で改行は空白化し先頭110字まで。データのない営業日は「この日の掲示板データはありません」と表示する。
- 権利上の注意: 投稿全文を公開ページで表示する形態は、取得可否とは別に「外部配信」に当たり得る（2026-11-14調査）。公開範囲の判断はオーナーが行う。

## Historical daily closing price dataset

- 取得銘柄：`285A.T`、東京証券取引所、JPY、`Asia/Tokyo`。
- ソース：Yahoo Finance、取得ライブラリ `yfinance`。
- 起点：2024-12-18（含む）。実行日の**前日まで**の確定済み取引日が対象。
- `yf.Ticker("285A.T").history(start="2024-12-18", end=<当日JST>, interval="1d", auto_adjust=False, actions=False)` を使用。
- 対象フィールド：`Close`。Yahoo Financeの履歴仕様に基づく**株式分割調整後・配当調整前**の価格。2026-09-29の1:3分割前も現在の株数基準に調整される。**各当時の非調整実勢終値ではない**。
- JSON保存先：`data/285A_daily_close.json`。1取引日1行、日付昇順。
- JSONの主な項目：`ticker`, `source`, `adjustment`, `start_date`, `last_trading_date`, `record_count`, `fetched_at_utc`, `prices: [{date, close}]`。
- 起点日欠落・空データ・不正な終値・日付重複は処理失敗とし、不完全なファイルで上書きしない。

## Updating data

- `scripts/fetch_285a_closes.py` が取得・JSON生成を実行。
- `.github/workflows/fetch-285a-closes.yml` は初回追加時のpushおよび手動 `workflow_dispatch` で実行。
- 成功時はGitHub Actionsが生成JSONを `main` へcommitする。日次定期更新は未設定。
- ブラウザゲームへのJSON読み込みは2026-11-14に実装済み（上記セクション）。
